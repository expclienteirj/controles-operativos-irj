Los 6 Ítems de Certificación (PET 7.1)

El pliego especifica exactamente estos 6 ítems:

1 Cumplimiento de Documentación Obligatoria 10%
Según PET: "Documentación previsional y de seguros. Ante un hallazgo evidenciado, corresponderá la penalización completa del ítem."
Código (calc.py):
def item_binario(hallazgos: int) → float:
  return 0.0 if (hallazgos or 0) > 0 else 1.0
Implementación correcta: 0 hallazgos = 1.0 (100%), ≥1 hallazgo = 0.0 (0%)
2 Cumplimiento Ley 19587 (Seguridad) 10%
Según PET: "Condiciones mínimas para prevención de riesgos laborales, elementos de protección personal, uniformes. Ante un hallazgo evidenciado, penalización completa."
Código (calc.py):
def item_binario(hallazgos: int) → float:
  return 0.0 if (hallazgos or 0) > 0 else 1.0
Implementación correcta: usa la misma función binaria que Documentación
3 Cumplimiento Programación de Trabajos 40%
Según PET: "Horas hombre mensuales programadas vs cumplidas. Penalidad proporcional por ausencias del personal."
Código (calc.py):
def item_programacion(horas_programadas, horas_perdidas):
  if not horas_programadas or horas_programadas <= 0:
    return None
  return _clamp((horas_programadas - horas_perdidas) / horas_programadas)
Fórmula: (Horas Programadas - Horas Perdidas) / Horas Programadas
Implementación correcta: proporción lineal del cumplimiento de horas
Ejemplo:
Programadas: 200 horas
Perdidas: 40 horas (ausentismo)
Score = (200 - 40) / 200 = 160 / 200 = 0.80 (80%)
4 Cumplimiento Maquinarias (Disponibilidad) 10%
Según PET: "Horas máquinas exigidas por el programa mensual. Penalidad proporcional por máquinas fuera de servicio."
Código (calc.py):
def item_maquinarias(exigidos, faltantes_por_dia):
  if not exigidos or exigidos <= 0 or not faltantes_por_dia:
    return None
  return promedio([ratio_sin_hallazgo(exigidos, f) for f in faltantes_por_dia])
Fórmula: PROMEDIO[(Exigidos - Faltantes) / Exigidos] por cada día auditado
Implementación correcta: promedia disponibilidad diaria, no acumula faltas
Ejemplo:
Exigidas: 3 máquinas
Día 1: 1 faltante → (3-1)/3 = 0.667
Día 2: 0 faltantes → (3-0)/3 = 1.0
Día 3: 1 faltante → (3-1)/3 = 0.667
Score = (0.667 + 1.0 + 0.667) / 3 = 0.778 (77.8%)
5 Cumplimiento Disponibilidad de Insumos 10%
Según PET: "Stock de insumos debe estar ≥ punto de pedido. Se certifica proporcionalmente: cantidad con stock OK / cantidad controlada."
Código (calc.py):
def item_insumos(insumos):
  if not insumos: return None
  ok = sum(1 for i in insumos if (i.get("stock") or 0) >= (i.get("punto_pedido") or 0))
  return ok / len(insumos)
Fórmula: (Insumos con stock ≥ punto de pedido) / (Total insumos controlados)
Implementación correcta: proporción de insumos en buen estado
Ejemplo:
Insumos controlados: 10
Con stock OK: 8
Sin stock: 2
Score = 8 / 10 = 0.80 (80%)
6 Cumplimiento Calidad de Servicio (Check-list) 20%
Según PET: "Calidad de servicio (limpieza de baños, techos, pasillos, etc.). La cantidad de no conformidades registradas determinará el porcentaje a certificar. Se ajusta por NC encontradas."
Código (calc.py):
def item_calidad_servicio(estado_general, nc_abiertas=0,
  penalizacion_nc=0.01, tope=0.20):
  if estado_general is None: return None
  descuento = min(nc_abiertas * penalizacion_nc, tope)
  return _clamp(estado_general - descuento)
Fórmula: Estado_General - min(NC_Abiertas × 1%, 20%)
Donde: Estado_General = promedio de check-list diarios
Implementación correcta: penalización por NC con tope del 20%
Ejemplo:
Estado general (check-list): 0.90 (90%)
No conformidades abiertas: 5
Penalización = min(5 × 0.01, 0.20) = min(0.05, 0.20) = 0.05
Score final = 0.90 - 0.05 = 0.85 (85%)
IMPORTANTE: La penalización por NC (1% por NC, tope 20%) es un supuesto de implementación. El pliego indica "cantidad de NC determinará porcentaje" pero NO especifica la fórmula exacta. Esta debe ser confirmada/ajustada según el Anexo II del pliego.

Cálculo Final de Certificación

Una vez calculados los 6 ítems, se aplica una ponderación y se obtiene el porcentaje final de certificación:

Código (calc.py):
def certificacion_mensual(items, pesos=None):
  pesos = pesos or PESOS_CERTIFICACION_DEFAULT
  evaluados = {k: v for k, v in items.items() if v is not None}
  # Si faltan ítems, el peso se redistribuye proporcionalmente
  peso_evaluado = sum(pesos[k] for k in evaluados if k in pesos)
  detalle = {}
  for k, v in evaluados.items():
    peso_norm = pesos[k] / peso_evaluado
    aporte = v * peso_norm
    detalle[k] = {"valor": v, "peso": pesos[k], "peso_normalizado": peso_norm, "aporte": aporte}

Certificación = Σ (Valor_Ítem × Peso_Normalizado)

= (Doc × 10%) + (Ley × 10%) + (Prog × 40%) + (Maq × 10%) + (Ins × 10%) + (Cal × 20%)

Si falta algún ítem, el peso se redistribuye proporcionalmente entre los evaluados.

Ejemplo Completo

Mes: Julio 2025 | Auditoría Mensual

Ítem Valor (%) Peso Aporte
1. Documentación 100% 10% 0.10 × 1.0 = 0.10
2. Ley 19587 100% 10% 0.10 × 1.0 = 0.10
3. Programación 85% 40% 0.40 × 0.85 = 0.34
4. Maquinarias 90% 10% 0.10 × 0.90 = 0.09
5. Insumos 95% 10% 0.10 × 0.95 = 0.095
6. Calidad 78% (85% - 7% NC) 20% 0.20 × 0.78 = 0.156
CERTIFICACIÓN MENSUAL 0.10 + 0.10 + 0.34 + 0.09 + 0.095 + 0.156 = 0.875 (87.5%)
La certificación de 87.5% significa que se certifica el 87.5% del monto adjudicado para ese mes.

Casos Especiales y Reglas Lógicas

1. Ítems sin Datos (None)

Regla implementada: Si un ítem no tiene datos (no se auditó, falta información), su valor es None y se excluye del cálculo. El peso se redistribuye entre los ítems evaluados.
Ejemplo:
Si falta Maquinarias (sin auditoría):
- Peso original: 10%
- Se redistribuye entre los 5 ítems restantes
- Los otros 90% se ponderan según su peso
- Certificación final = Σ(ítems_con_datos × peso_normalizado)
Regla correcta: no medir ≠ medir mal. No se penaliza por datos faltantes.

2. Cobertura Mínima del Mes (Limpieza Diaria)

Regla implementada: El control de limpieza es diario. Se requiere una cobertura mínima (default 80%) de días auditados. Si no se alcanza, la certificación advierte pero se calcula igual.
Código:
COBERTURA_MINIMA_DEFAULT = 0.80
cobertura = len(auditados) / len(esperados)
cobertura_suficiente = cobertura >= COBERTURA_MINIMA_DEFAULT
Regla correcta: se advierte pero no invalida automáticamente

3. Descuento por No Conformidades (Tope)

Regla implementada: Cada NC abierta descuenta un porcentaje de Calidad de Servicio, pero con tope máximo del 20%.
descuento = min(nc_abiertas * 0.01, 0.20)
valor_final = _clamp(estado_general - descuento)
ACLARACIÓN: El tope del 20% es un supuesto de implementación. El pliego NO especifica un tope explícito. Debe confirmarse contra Anexo II.

4. Validación de Rangos (Clamp)

def _clamp(x):
  return max(0.0, min(1.0, x))

# Garantiza que ningún valor salga del rango [0.0, 1.0]
Regla correcta: los porcentajes nunca pueden ser negativos ni > 100%

Tolerancia Numérica (EPS)

EPS = 1e-9 # Tolerancia para comparaciones de punto flotante

def cumple(valor, objetivo):
  return valor >= objetivo - EPS
Justificación: Las comparaciones de punto flotante pueden fallar por representación binaria. Por ejemplo, 4/5 podría no ser exactamente 0.80 en binario. EPS = 1e-9 asegura que decisiones críticas (¿cumple 80%?) no falten por errores de redondeo.
Regla correcta: protege contra errores numéricos de máquina
