Ítem 4: Iluminación

4 Luminarias Encendidas
Según LoS:
  • Objetivo: 90% de las luces funcionando
  • Restricción: NO se permiten 2+ luces quemadas consecutivas en el MISMO CONO DE LUZ
  • Para IRJ Verano: Horario de medición 22:00
  • Para IRJ Invierno: Horario de medición 20:00
Código (calc.py):
def iluminacion_sector(total_luminarias, quemadas, consecutivas_mismo_cono=False):
  pct = ratio_sin_hallazgo(total_luminarias, quemadas)
  umbral_ok = cumple(pct, 0.90)
  ok = umbral_ok and not consecutivas_mismo_cono
  return {"porcentaje": pct, "umbral_ok": umbral_ok, "cumple": ok, ...}
Fórmula:
% = (Total - Quemadas) / Total
cumple = (% ≥ 90%) AND (NO hay 2+ luces consecutivas en mismo cono)
Implementación correcta: valida tanto umbral de % como la restricción de conos
Ejemplo:
Sector A: 20 luces totales, 2 quemadas (no consecutivas)
% = (20-2)/20 = 90% ✓ Cumple umbral
Consecutivas en cono: No ✓ Cumple restricción
Resultado: ✓ CUMPLE

Ítem 5: Estado de Infraestructura

5 Grado de Condición (Escala A/B/C/D)
Según LoS:
  • A: Satisfactorio (0 hallazgos)
  • B: Mejoras (hallazgos menores)
  • C: Mejoras considerables (genera No Conformidad PROGRAMADA)
  • D: Insatisfactorio (riesgo de golpes/lesiones, genera NC INMEDIATA)
  • Cumple si: A o B
Código (calc.py):
GRADOS_QUE_CUMPLEN = {"A", "B"}
PRIORIDAD_NC = {"C": "PROGRAMADA", "D": "INMEDIATA"}

def evaluar_grado(grado):
  ok = grado.upper() in GRADOS_QUE_CUMPLEN
  genera_nc = not ok
  prioridad_nc = PRIORIDAD_NC.get(grado)
Regla:
cumple = grado ∈ {A, B}
Si grado = C → No Conformidad PROGRAMADA
Si grado = D → No Conformidad INMEDIATA
Implementación correcta: escala A/B/C/D con generación automática de NCs
Ejemplo - Veredas:
Auditor observa grietas < 1cm: Grado B → ✓ CUMPLE
Auditor observa grietas > 1cm: Grado D → ✗ NO CUMPLE, genera NC INMEDIATA

  • PAX promedio por aeronave: 76 (estándar IATA)
  • Requisito IATA: 50% de asientos mínimo

Código (calc.py):
ASIENTOS_MINIMOS_IRJ = 38

def asientos_preembarque(instalados, inutilizables=0, minimo=38):
  utilizables = max(0, instalados - inutilizables)
  cumple = utilizables >= minimo
  return {"utilizables": utilizables, "minimo": minimo, "cumple": cumple}
Fórmula:
Utilizables = Instalados - Inutilizables
cumple = Utilizables ≥ Mínimo
Implementación correcta: descuenta asientos inutilizables
Ejemplo - IRJ:
Asientos instalados: 50
Inutilizables: 5
Utilizables: 50 - 5 = 45
Mínimo requerido: 38
Cumple: 45 ≥ 38 → ✓ CUMPLE

Ítem 7: Puntos de Carga

7 Tomas de Corriente (25 por 100 PHP)
Según LoS:
  • Estándar: 25 tomas de corriente por cada 100 pasajeros en hora pico (PHP)
  • Se calcula por puerta de embarque
  • Fórmula: Tomas requeridas = CEILING(PHP × 25 / 100)
Código (calc.py):
TOMAS_POR_100_PAX = 25

def tomas_requeridas(php):
  return math.ceil(php * 25 / 100)

def puntos_de_carga(puerta):
  req = tomas_requeridas(puerta["php"])
  operativas = puerta["instaladas"] - puerta["fuera_servicio"]
  cumple = operativas >= req
Fórmula:
Requeridas = ⌈PHP × 25 / 100⌉
Operativas = Instaladas - Fuera de Servicio
cumple = Operativas ≥ Requeridas
Implementación correcta: usa CEILING para no redondear hacia abajo
Ejemplo - Puerta de embarque:
PHP: 120 pasajeros
Requeridas: ⌈120 × 25 / 100⌉ = ⌈30⌉ = 30
Instaladas: 35
Fuera de servicio: 2
Operativas: 35 - 2 = 33
Cumple: 33 ≥ 30 → ✓ CUMPLE

Ítem 11: Pista y Rodajes (PCI)

11 Disponibilidad y PCI (Índice de Condición del Pavimento)
Según LoS:
  • Disponibilidad: 100% durante horario operativo (salvo mantenimiento programado)
  • PCI: Índice de 0-100 de condición superficial del pavimento
  • Pista: 85% de secciones con PCI > 70
  • Rodajes: 70% de secciones con PCI > 60
  • Estándares: ASTM D6433 y ASTM D5340
Código (calc.py):
PCI_PISTA = {"umbral": 70, "proporcion_min": 0.85}
PCI_RODAJE = {"umbral": 60, "proporcion_min": 0.70}

def pci_secciones(secciones, tipo):
  p = PCI_PISTA if tipo == "PISTA" else PCI_RODAJE
  sobre_umbral = [s for s in secciones if s["pci"] > p["umbral"]]
  proporcion = len(sobre_umbral) / len(secciones)
  cumple = proporcion >= p["proporcion_min"]
Fórmula:
Para PISTA: Proporción = Secciones(PCI>70) / Total
  cumple = Proporción ≥ 85%

Para RODAJES: Proporción = Secciones(PCI>60) / Total
  cumple = Proporción ≥ 70%
Implementación correcta: diferentes umbrales y proporciones por tipo
